# ユーザー・ペルソナ・ロール、用語集

## 1. ロール一覧

[継承・具体化] 管理者／一般ユーザの2種類とする。招待時に管理者が設定し、登録完了後も
管理者が双方向に変更できる（詳細は`02-functional-requirements.md`「1. ユーザ登録・認証」）。

| ロール名 | 概要 | 主要ユースケース |
|---|---|---|
| 管理者 | ユーザ招待・ロール設定・接続設定・権限設定・監査ログ閲覧を行う | ユーザのメールアドレス登録（招待）とロール設定、RDBMS接続登録、スキーマ取込、権限設定、グループ管理、監査ログ確認 |
| 一般ユーザ | 権限範囲内でマスタデータの閲覧・編集・クエリ実行を行う | 招待メールからの本登録完了、データ閲覧・編集、クエリビルダー利用、保存クエリ実行、クエリ履歴閲覧 |

## 2. ペルソナ（User Storiesステージが実行される場合に備えて）

[継承]
- 管理者: 社内システム管理を兼務する担当者。ユーザの入退社に応じてアカウントを招待・無効化し、
  部署やチームに応じて権限を設定する
- 一般ユーザ: 普段DBを直接触らない業務担当者。SQLの知識はない、またはクエリビルダーで
  補助されることを前提とする

## 3. 用語集

プロジェクト内で使う用語の定義を一箇所に集約する。他ファイルではここで定義した用語を
そのまま使い、別の言い回しをしない（表記揺れは追加質問を誘発する）。

| 用語 | 定義 |
|---|---|
| 招待 | 管理者がメールアドレスとロールを登録し、招待メールを送信する操作。ユーザはこのメールの
  リンクから本登録を完了する（`[変更]`点。旧仕様の「登録申請」に相当する概念を置き換えた） |
| ロール | ユーザに付与される「管理者」「一般ユーザ」のいずれかの属性。招待時に設定し、
  登録完了後も管理者が変更できる |
| カスタマイズ定義 | マスタメンテナンス画面の表示・入力を調整するYAML定義（表示ラベル・列順・
  初期ソート、入力ウィジェット種別、列の非表示・読取専用化、簡易バリデーション）。対象RDBMS
  接続ごとに持つ。権限モデルを上書きしない（`[追加]`点） |
| 主権限 | スキーマ／テーブル／カラムの各階層に設定する読み書きレベル（NONE/READ/UPDATE）の3値 |
| 補助権限 | スキーマ／テーブル単位に設定するCREATE/DELETEの可否を表す独立した真偽値 |
| 実効権限 | ユーザ個別設定とグループ設定を合成した最終的な権限 |
